## 运行方法

### Windows

1. 解压到任意文件夹
2. 双击 `AK card game.exe`
3. 如果被杀毒软件拦截，选择"允许运行"

### macOS

Mac 版是在 Windows 上交叉打包的，第一次打开会被系统拦截。

**第一步**：解压到任意文件夹

**第二步**：如果双击提示"无法打开"或"已损坏"，打开终端执行：

```bash
xattr -cr "/你的路径/AK card game.app"
chmod +x "/你的路径/AK card game.app/Contents/MacOS/AK card game"
```

**第三步**：右键点 app → 选择"打开" → 再点一次"打开"

（第一次绕过 Gatekeeper 后，以后就能正常双击了）

如果提示"未受信任的开发者"：
系统设置 → 隐私与安全性 → 拉到最下面 → 点"仍要打开"

## 玩法简介

- 1v1 回合制卡牌，把对面博士的 20 点生命打到 0
- 费用每回合 +1（最高 10），进阶点先手 2 / 后手 3
- 五个阵营：乌萨斯、维多利亚、哥伦比亚、卡兹戴尔、海嗣
- 支持单机（AI）与联机对战

详细规则见压缩包内的 **《新手入门》**。
